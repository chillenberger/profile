# Overview
Dan's profile website.  A very quick and not at all encompassing overview of some of my career. This is almost guaranteed to be out of date.  Please just reach out if you have any questions. 

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
